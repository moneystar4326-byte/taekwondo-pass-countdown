# 태권도 승품·단 심사 합격 카운트다운

도장 빔프로젝터나 큰 화면에서 승품·단 심사 합격자를 한 명씩 카운트다운과 함께 발표하는 웹앱입니다.

👉 **바로 써보기: https://moneystar4326-byte.github.io/taekwondo-pass-countdown/**

설치 없이 위 링크를 크롬으로 열면 됩니다. 입력한 명단·사진·로고는 각자 브라우저에만 저장되고 서버로 전송되지 않습니다.

## 주요 기능

- 3초 / 5초 카운트다운 + 드럼롤·팡파레 효과음 + 축하 폭죽
- 수련생 명단 관리 (추가·수정·삭제, 품/단 선택, 맞춤 축하 메시지)
- 수련생 사진 등록: 버튼, 화면에 끌어다 놓기, 복사 후 붙여넣기(Ctrl+V)
- 도장 로고 등록 (설정 → 도장 로고), 배경 테마 5종
- 합격증서 보기 및 인쇄 / PDF 저장

## 단축키

| 키 | 동작 |
|---|---|
| Space | 카운트다운 시작 / 즉시 공개 |
| ← → | 이전 / 다음 수련생 |
| F | 전체화면 |
| M | 효과음 켜기 / 끄기 |
| Esc | 열린 창 닫기 |

## 내 컴퓨터에서 실행하기 (개발용)

[Node.js](https://nodejs.org) 20 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## 사이트 다시 배포하기

코드를 고친 뒤 아래 명령을 실행하면 `gh-pages` 브랜치로 사이트가 갱신됩니다 (Git Bash 기준).

```bash
npm run deploy
```
